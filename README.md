# Cold Logic — legal pages

Public legal pages for the Cold Logic app, served via GitHub Pages.

The app's source lives in the private `erenavar/cold-logic` repository. This repo exists
only because GitHub Pages requires a public repository on the current plan, and the app's
source is not meant to be public. Nothing here is app source — only content that was
always meant to be publicly readable.

- `privacy-policy.md` — linked from the Play Store listing.
